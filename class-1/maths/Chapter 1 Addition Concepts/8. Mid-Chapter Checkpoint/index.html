H.O.T. Birds on a Branch 🐦

There are 5 birds on a branch in total. 3 are red birds. Some blue birds join them.

Touch the birds to color 3 RED and the remaining BLUE!

Tap each picture to switch: no color → red → blue → no color.

How many blue birds are there?

Choose an answer for question 1

Short solution
