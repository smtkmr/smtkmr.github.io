A tiny maths warm-up

Two groups.
One happy discovery.

There are 3 red apples and 2 green apples. How many apples are there altogether?

Count both groups, then choose your answer.

🍎🍎🍎 + 🍏🍏

3 + 2 = ?

Choose an answer, then check it.

Short solution

Start with 3 red apples. Count on 2 more: 4, 5. So 3 + 2 = 5 apples.

Big confidence starts with little wins. 💛

Count real objects together and ask, “How did you work that out?” Celebrate the thinking, the trying and every little step forward.
