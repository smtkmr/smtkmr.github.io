Add zero.
Stay the same.

Zero means nothing is added. Add zero to a number—or a number to zero—and that number stays the same. Let’s see it, try it and discover it together!

01 · Model and draw

An empty group adds nothing.

Count the dots in both boxes. An empty box means zero.

Start with 5. Add nothing.

+
Empty · 0 dots
5 + 0 = 5

5 red dots in the left box. No dots in the right box. There are still 5 dots.

Start with nothing. Add 3.

Empty · 0 dots
+
0 + 3 = 3

No dots in the left box. 3 green dots in the right box. There are 3 dots in all.

Remember: A number + 0 = the same number. And 0 + a number = that number too!

Mike & Cheryl’s books

Mike · 7 books
Cheryl · 0 books

Short solution

Mike has 7 books and Cheryl has 0. Put their books together: 7 + 0 = 7 books.

3 dogs sitting
5 dogs joining

Short solution

Thinking challenge · Question 20Your turn

Who is inside the birdhouse?

There are 5 birds altogether. You can see 4 birds outside the birdhouse: 1 purple, 1 yellow, 1 green and 1 blue. How many birds are inside?

?

4 birds outside

Short solution

There are 5 birds altogether and 4 outside. 5 − 4 = 1 bird inside. You can check: 4 + 1 = 5.
