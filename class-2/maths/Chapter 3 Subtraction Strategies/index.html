Worksheet Strategy Summary

6 Subtraction Laws!
• 1. Count Back Rule: बड़ी संख्या (Minuend) से शुरू करें और छोटी संख्या (Subtrahend) जितने कदम नंबर लाइन पर पीछे गिनें।
• 2. Subtract Zero (a - 0 = a): 0 घटाने पर संख्या वही रहती है (3 bees - 0 = 3 bees)।
• 3. Subtract All (a - a = 0): पूरी संख्या घटाने पर शून्य (0) बचता है (8 candles - 8 = 0)।
• 4. Doubles Strategy: 8 + 8 = 16 ➔ 16 - 8 = 8 (Brian's CDs, Fran's pumpkins)।
• 5. Related Fact Rule: जोड़ और घटाव एक दूसरे के विपरीत होते हैं (7 + 5 = 12 ➔ 12 - 5 = 7)।
• 6. Fact Family Rule: 3 संख्याएं मिलकर 4 गणितीय वाक्य बनाती हैं (2 जोड़ और 2 घटाव)।
Worksheet 3-1 · Count Back to Subtract

1. Count Back to Subtract: Using the Number Line (संख्या रेखा पर पीछे गिनना)

A. How to Count Back: Start at [X], Count back [Y] steps to reach [Z]

Standard 2NS2.2

संख्या रेखा (Number Line) पर घटाने के लिए हम बड़ी संख्या (Minuend) से शुरू करते हैं और बाईं ओर (पीछे) कूदते हैं:

👉 सरल हिंदी व्याख्या (वर्कशीट 3-1):
• 12 - 5: संख्या 12 से शुरू करें और 5 कदम पीछे कूदें (11, 10, 9, 8, 7)। आप 7 पर पहुँचते हैं! वाक्य: 12 - 5 = 7.
• 10 - 6 (रिकी के संतरे): 10 से 6 कदम पीछे कूदने पर 4 आता है। वाक्य: 10 - 6 = 4.
• 12 - 4 (कार वॉश तुलना): 12 कारें और 4 ट्रक ➔ 12 - 4 = 8 कारें अधिक!
⚠️ सावधान! सामान्य गलती (Student Trap): शुरुआती संख्या को ही पहला कदम न गिनें! यदि आप 12 से शुरू कर रहे हैं, तो पहला कदम 11 पर होगा, 12 पर नहीं!
Worksheet 3-2 · Subtract All and Zero

2. Subtract All and Subtract Zero (सभी को घटाना और शून्य घटाना)

A. The Two Fundamental Identity Rules (दो स्वर्णिम नियम)

2NS2.2, 2MR1.2
Rule 1: Subtract Zero
Number - 0 = Same Number

जब आप किसी संख्या में से 0 (कुछ नहीं) घटाते हैं, तो वह संख्या वैसी ही रहती है!
• 3 bees buzz, none fly away: 3 - 0 = 3
• Mrs. Keen feeds 8 squirrels, none run away: 8 - 0 = 8
• Facts: 6 - 0 = 6, 9 - 0 = 9, 4 - 0 = 4, 7 - 0 = 7, 8 - 0 = 8.

Rule 2: Subtract All
Number - Same Number = 0

जब आप किसी संख्या में से सभी (All) घटा देते हैं, तो केवल 0 बचता है!
• 8 candles on cake, Javier blows out all 8: 8 - 8 = 0
• 5 sparrows in nest, they all fly away: 5 - 5 = 0
• 8 ducks in pond, all fly away: 8 - 8 = 0
• Miguel catches 7 spiders, lets all go: 7 - 7 = 0
