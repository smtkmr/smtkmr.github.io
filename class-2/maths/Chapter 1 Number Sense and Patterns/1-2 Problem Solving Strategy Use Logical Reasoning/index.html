Use Logical Reasoning

A simple thinking routine

How to reason it out

Slow down, use the clues, then check.

🔎

1. Find the clues

Notice the numbers and words like more, less, before, after, all and some.

🧩

2. Try possibilities

Use counters, a number line, a picture, or a short list. Cross out choices that break a clue.

✅

3. Check every clue

Test your answer in the story. It is correct only when it fits all the clues.

Let’s reason together

Which number is Mia thinking of?

It is greater than 30, less than 40, and has 5 ones. The tens digit must be 3. The ones digit must be 5. So the number is 35.
