Class 2 Maths · Chapter 1 · Topic 1-8

Problem-Solving Investigation: Make a List

When a problem asks “What are all the ways?” or “What could happen?”, make an organized list. Work through choices one at a time so you do not miss or repeat an answer.

Start 30 list-making challenges ↓Learn the strategy
30CHALLENGES

A strategy for finding every answer

Make a list, keep it organized

Use a list when there are several possible choices or arrangements.

🗂️

Start with one choice

Write down the first choice. Then list every possible partner or result for that choice.

🔎

Follow the clues

Cross out choices that do not fit. Keep the ones that follow every rule in the problem.

✅

Check for all and only

Make sure no answer is missing and none is written twice. A clear list helps you check.

Example · snack choices

2 fruits and 2 drinks: how many snack pairs?

Pair each fruit with each drink. Start with apple, then list every drink. Repeat for banana.

1. Apple + water2. Apple + milk3. Banana + water4. Banana + milk
1

Read the question

Notice how many choices there are and what the question asks you to find.

2

Make a tidy list

Use one choice at a time. Write each matching possibility beside it.

3

Count and check

Count the entries, look for repeats, and make sure every clue is followed.

Helpful tools: You can make a list with words, numbers, a table, or quick pictures. Choose the way that makes the possibilities easiest to see.
