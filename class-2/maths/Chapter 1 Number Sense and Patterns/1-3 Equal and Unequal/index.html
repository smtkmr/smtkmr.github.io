Equal and Unequal

Compare groups, numbers and number sentences. Equal means the amounts are the same; unequal means they are different. Look carefully, count fairly and explain how you know.

Start 20-question practice ↓Learn with examples
20CHALLENGES

First, learn the idea

When are things equal?

Count both sides and compare carefully.

⚖️

Equal means same

Two groups are equal when they have the same number. Their objects may look different, but the count matches.

=
🔍

Unequal means different

Groups are unequal when one has more or fewer than the other. The not-equal sign is ≠.

≠
🧮

Both sides must balance

A number sentence is equal when both sides have the same value. Work out each side before deciding.

left = right

Same amount

Four green counters and four yellow counters

4=4

Both groups have 4. The groups are equal.

Different amounts

Five counters and three counters

5≠3

5 is more than 3, so the groups are unequal.

1

Count each side

Touch or point to each object once. Check that you did not skip or count one twice.

2

Compare the totals

Ask: are the totals the same, or is one greater? For number sentences, find each side’s value.

3

Choose and explain

Use = for same and ≠ for different. Say what you counted or worked out.

Remember: Equal groups do not have to look alike. Five red blocks and five blue blocks are still equal because both groups contain five.
